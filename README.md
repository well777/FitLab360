Projeto: FitLab 360 - Landing Page Fitness
Desenvolvedor Front-End

Descrição:
Desenvolvimento de uma Landing Page de alto impacto para a marca FitLab 360, focada na conversão de alunos e exposição de serviços de consultoria fitness. O projeto utiliza uma estética Dark Mode com acentos em Neon Green, garantindo uma identidade visual moderna e profissional.

Destaques Técnicos:

Arquitetura Semântica (HTML5): Estruturação focada em SEO e acessibilidade, garantindo que o conteúdo seja interpretado corretamente por motores de busca.

Estilização Avançada (CSS3): Uso de Flexbox e Grid Layout para criar uma interface totalmente responsiva, adaptando-se perfeitamente de desktops a dispositivos móveis.

Interatividade (JavaScript): Implementação de comportamentos dinâmicos no DOM, como navegação suave (smooth scroll), menus responsivos e interações nos cards de planos e treinadores.

Foco em UX/UI: Criação de seções estratégicas como Tabela de Preços, Portfólio de Treinadores e Prova Social (Depoimentos), otimizando a jornada do usuário.

Tecnologias Utilizadas:

Linguagens: HTML5, CSS3, JavaScript (ES6+).

Metodologia: Design Responsivo e Mobile-First.

Ferramentas: VS Code, Git e inspeção de performance no navegador.
